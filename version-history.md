# Version history

Every save in Cellar is kept as a version, so mistakes can always be undone.

## Open history

Click **History** in the Cellar bar. Each version shows:

- what happened: "Started from template: Budget", "Imported budget.xlsx",
  "Added chart: Sales", "Restored the version from Today 14:31:05" or "Edited"
- the exact time, for example "Today 14:31:05" (hover for "5 min ago")
- who saved it

## Preview a version

Click **Preview** to see that version read-only on the page. A blue bar shows
which version you are looking at, with **Restore this version** and **Back to
current**.

## Restore a version

Click **Restore** (then **Click to confirm**), or **Restore this version** while
previewing. The old version is copied forward as a new version, so your current
version stays in history too. Nothing is ever overwritten.

Only people who can edit the page can restore. Anyone who can view it can preview.

## If two people save at once

Both versions are kept. The later save becomes current, and the bar says another
person's version is in history.

## How long versions are kept

- Every version from the last 24 hours
- One version per hour for the last 30 days
- One version per day after that

The current version is always kept.
