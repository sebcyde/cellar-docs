# Charts

## Add a chart

1. Make sure the sheet is not open for editing (click **Done**).
2. **File ▾ › Add a chart…**
3. Choose a type (**Bar**, **Line**, **Area** or **Pie**), a title, the sheet, and
   a data range such as `A1:C6`.
4. Click **Add chart**.

## How the range is read

- The first column holds the labels (for example months or categories).
- Each further column is one series of values.
- If the first row contains text above the value columns, it is used as the series
  names.
- Pie charts use the first value column.

## Notes

- Charts are saved with the sheet, so they are part of version history.
- Charts update when the sheet's values change.
- Click **Remove** on a chart to delete it (it stays in history).
- Charts are shown below the sheet in the read-only view.
