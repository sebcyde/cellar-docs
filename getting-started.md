# Getting started with Cellar

Cellar adds a real spreadsheet to any Confluence page.

## Add a spreadsheet to a page

1. Edit a Confluence page.
2. Type `/cellar` (or use the **+** insert menu and search for "Cellar"), then
   choose **Cellar spreadsheet**.
3. Choose how to start:
   - **Blank sheet**
   - **Import Excel or CSV**: pick an `.xlsx`, `.csv` or `.tsv` file
   - **Use a table from this page**: turns an existing Confluence table into a sheet
   - **A template**: Budget, OKRs, Project tracker, Inventory, RACI matrix,
     Risk register, Sprint capacity, Meeting actions, Pricing calculator or
     Timesheet
4. Your sheet saves automatically. The bar shows "All changes saved".

## Viewing and editing

- Readers see a fast, read-only table with formatting, number formats and sheet tabs.
- Click **Edit** to open the full spreadsheet editor, and **Done** when finished.
- Changes save automatically about a second after you stop typing, and when you
  click Done.

## Who can edit

Cellar follows the page's permissions. If you can edit the page, you can edit its
sheets. Everyone else sees a read-only view with a **View only** badge and can
still download the data.

## What's in the editor

- Formulas, number formats, merged cells, multiple sheets, frozen panes
- **Data** tab: sort, filter, tables, dropdowns (data validation), conditional
  formatting, find and replace
- **Insert** tab: hyperlinks, images, notes
- Paste from Excel or Google Sheets
