# FAQ and troubleshooting

**I can't see the Edit button.**
Cellar follows page permissions. Ask for edit access to the page, or check
whether the page has edit restrictions.

**The sheet says my subscription isn't active.**
The Cellar licence for your site has lapsed. Sheets stay viewable and
downloadable. A Confluence admin can renew Cellar in **Manage apps**.

**My old .xls file won't import.**
Open it in Excel, choose **File › Save As › Excel Workbook (.xlsx)**, then import
the new file.

**I made a mistake. Can I undo it?**
Yes. Use Undo in the editor, or **History › Preview › Restore this version**.
Restoring never deletes anything.

**Where is my data stored?**
In your Atlassian site's own storage, on Atlassian's infrastructure. Cellar never
sends it to outside servers.

**How big can a sheet be?**
Imports up to 50 MB. The page view shows the first 200 rows and 40 columns; the
editor shows everything.

**The sheet is blank in the Confluence mobile app.**
Confluence's iOS and Android apps don't display Forge apps yet, which affects
all apps built on Atlassian's current platform, not only Cellar. Open the page
in a web browser instead (on a phone or computer) and the sheet appears.

**Does Cellar work in dark mode?**
Yes. It follows your Atlassian theme.

**Can I have more than one sheet on a page?**
Yes. Each Cellar macro is its own independent sheet, and each can have several
tabs.

**Something else is wrong.**
Contact support at [the support page](support.md).
